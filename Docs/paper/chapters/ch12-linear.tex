\chapter{Linear Logic, Cut Elimination, and Zero Allocation}\label{ch:linear}

Linear logic is the logic of resources used exactly once \citep{girard}: its formulas cannot be duplicated or discarded freely, and its cut rule composes proofs exactly as Mol composes molecules. The reason a dataplane can promise zero allocation on the hot path is that a dataplane is a linear program (every datum is produced once and consumed once) and the intermediate structures a classical program would materialize are eliminated by fusion. That elimination is cut elimination, known in programming as deforestation \citep{wadler}. This chapter proves that cut elimination fuses every pure pipeline into a single molecule (\autoref{thm:49}), that linear atoms force zero allocation (\autoref{thm:50}), and records the geometry-of-interaction and Curry--Howard readings of these results.

\paragraph{Pipelines and cuts.}
A pure pipeline is a composite $p = g_n \circ \cdots \circ g_1 : A_0 \to A_n$ of molecules $g_i : A_{i-1} \to A_i$. In the categorical semantics of linear logic, each composition point $g_{i+1} \circ g_i$ is a \emph{cut}: a proof of $A_{i-1} \to A_i$ glued to a proof of $A_i \to A_{i+1}$ across the intermediate formula $A_i$. Cut elimination rewrites a proof until no cut remains; its semantic content is that the composite morphism is computed directly, without ever constructing the intermediate object of type $A_i$ \citep{girard}. In a dataplane the intermediate object is a materialized buffer, and cut elimination is deforestation: the buffer is fused away \citep{wadler}.

\begin{theorem}[Cut elimination as deforestation (\autoref{thm:49})]\label{thm:49}
Every pure pipeline $p = g_n \circ \cdots \circ g_1 : A_0 \to A_n$ in Mol is equal to a single molecule $h : A_0 \to A_n$, the \emph{fused pipeline}, with the following properties:
\begin{enumerate}
\item $h \simeq p$: fusion preserves behavior;
\item the intermediate types $A_1, \ldots, A_{n-1}$ never materialize as buffers during the execution of $h$: no datum of type $A_i$ is stored between stages;
\item $h$ is constructed from the presentations of the $g_i$ by an explicit finite procedure of worst-case complexity $O\bigl (|S_1| \cdots |S_n| \cdot (|A_0| + \cdots + |A_{n-1}|)\bigr)$, where $|S_i|$ is the size of the state space of $g_i$.
\end{enumerate}
\end{theorem}

\begin{proof}
First fuse two molecules. Let $f : A \to B$ and $g : B \to C$ be presented by $(S_f, s_f, \delta_f)$ and $(S_g, s_g, \delta_g)$. Define $h : A \to C$ with state space $S_f \times S_g$, initial state $(s_f, s_g)$, and transition
\[
\delta_h\bigl ((u, v), a\bigr) = \bigl (c, (u', v')\bigr),
\qquad \text{where } (b, u') = \delta_f (u, a), \quad (c, v') = \delta_g (v, b) .
\]
This is a valid Mealy machine, and by the definition of composition in Mol (\autoref{ch:mol}) it is exactly the composite $g \circ f$: on every input word, $h$ follows the same state trajectory $(u, v) \mapsto (u', v')$ and emits the same output word as the two-stage machine, so $h \simeq g \circ f$. In a single transition of $h$, the value $b$ is produced by $\delta_f$ and consumed by $\delta_g$ within that same transition; it is held in a register and never stored, so no buffer of type $B$ exists in this realization.

Now iterate. By induction on $n$, the pipeline $g_{n-1} \circ \cdots \circ g_1$ is equal to a single molecule $h' : A_0 \to A_{n-1}$ with state space $S_1 \times \cdots \times S_{n-1}$ and no intermediate buffers; fusing $h'$ with $g_n$ by the two-molecule construction gives the single molecule $h$ with state space $S_1 \times \cdots \times S_n$, behavior equal to $p$, and no buffer of any type $A_i$ ($1 \leq i \leq n-1$). The transition table of $h$ has $|S_1| \cdots |S_n| \cdot |A_0|$ entries, each computed by one step of every $g_i$ (work $O (|A_0| + \cdots + |A_{n-1}|)$), giving the stated construction cost. This is the cut-elimination theorem of linear logic \citep{girard} realized concretely in Mol; in programming terms it is deforestation, the elimination of the intermediate data structure \citep{wadler}.
\end{proof}

\paragraph{Remark (fusion cost).}
The fused machine is a morphism of Mol, so by the additivity of the cost model (\autoref{thm:25}) its cost is at most the sum of the component costs; because the intermediate value is transient, the buffer copy that a two-stage realization pays is absent, which is the content of the fusion bound (\autoref{thm:27}): $c (g \circ f) \leq c (f) + c (g)$, strict when the intermediate type never materializes. \autoref{thm:49} supplies the mechanism behind that bound.

\paragraph{Linearity and ownership.}
Call an atom $f : A \to B$ \emph{linear} if for every state $s$ and every input $a$ in its domain, the transition $(b, s') = \delta (s, a)$ reads $a$ exactly once and produces exactly one output $b$. A linear atom never copies its input, never drops it, and never holds it past the transition that consumes it; at every instant each datum is \emph{owned} by exactly one atom. This is the ownership discipline of Rust restated as a property of molecules.

\begin{theorem}[Linearity forces zero allocation (\autoref{thm:50})]\label{thm:50}
Let $M$ be a molecule built from linear atoms by the operations $\circ$, $\otimes$, and the batch construction of \autoref{ch:operad}. Then:
\begin{enumerate}
\item $M$ is linear: it consumes every input datum exactly once;
\item along every execution of $M$ the number of live data tokens is invariant: each transition consumes exactly one token and produces exactly one token;
\item consequently, if the buffers of $M$ are preallocated to their maximum occupancy (bounded by the ring invariant, \autoref{thm:48}), the hot path performs no allocation and no deallocation.
\end{enumerate}
\end{theorem}

\begin{proof}
(i) By induction on the construction of $M$. An atom is linear by hypothesis. Composite: in $g \circ f$, an input token $a$ is read exactly once by $f$ (linearity), producing exactly one token $b$; $b$ is read exactly once by $g$ (linearity), producing exactly one token $c$; so the composite reads $a$ exactly once and emits exactly one output. Tensor: $f \otimes g$ on a pair $(a, a')$ reads $a$ exactly once in $f$ and $a'$ exactly once in $g$ and emits exactly one pair. Batch: $f^{(n)}$ reads each of its $n$ inputs exactly once by the definition of the batch transition and emits exactly $n$ outputs. Every molecule is obtained by finitely many such steps, so (i) holds.

(ii) Fix an execution and let $L (t)$ be the number of data tokens in the buffers and in flight at time $t$. By (i) every transition consumes exactly one token and produces exactly one token, so $L$ is unchanged by every transition: $L (t) = L (0)$ for all $t$.

(iii) By (ii) occupancy never exceeds $L (0)$. If each stage buffer is preallocated with capacity at least its share of $L (0)$ (a ring of capacity $2^k \geq L (0) + 1$ per stage satisfies the in-flight bound $w - r \leq 2^k - 1$ of \autoref{thm:48}), then every write fits in preallocated storage and every read empties a slot in place. No token is copied, created, or destroyed, so the execution acquires and releases no heap memory: zero allocations and zero deallocations on the hot path.
\end{proof}

\paragraph{Geometry of interaction.}
In Girard's geometry of interaction a proof is interpreted as an operator, and cut elimination is the \emph{execution} of that operator: a token travels through the proof, and cuts are crossed by iterating the operator until the token exits \citep{girard, arxiv-linear-logic-goi}. The reading in Mol is literal: a datum is a token, an atom is a transition $\delta$ that carries the token from its input port to its output port, and a molecule is the composition of these port-to-port maps. The fusion theorem (\autoref{thm:49}) is the execution: it computes in one pass the effect of the whole pipeline on any token, without materializing the cut formulas. The token interpretation is also the performance claim: the working set is the set of live tokens, invariant by \autoref{thm:50}, which bounds the cache-miss component of the cost vector of \autoref{ch:enrich}.

\paragraph{Curry--Howard for molecules.}
Read propositions as types and proofs as molecules: the linear implication $A \multimap B$ is the type of molecules $A \to B$, and composition is the cut rule; a well-typed dataplane element is a proof of its interface type. The theorems of this chapter upgrade this typing discipline to a resource guarantee: if the type system records that every atom is linear (the hypothesis of \autoref{thm:50}) and that fusion removes intermediate structure (\autoref{thm:49}), then a well-typed hot path is allocation-free by construction. This is the categorical content of ownership in Rust: a discipline of exact-once consumption is precisely the data that parts (ii)--(iii) of \autoref{thm:50} require, so the guarantee is enforced at compile time rather than by runtime measurement \citep{wadler}.

\section{The Affine Type System and the No-Allocation Theorem}\label{sec:linear-affine}

The ownership discipline of \autoref{thm:50} is stated as a semantic hypothesis: atoms are assumed to consume their input exactly once. This section shows that the hypothesis can be \emph{enforced} rather than assumed, by a small affine type system $\Lambda$ whose well-typed terms are exactly the molecules of Mol built by composition and tensor. The system is affine in the sense of the affine fragment of linear logic: every variable may be used at most once, so no term can copy or drop a datum, and reduction (the operational semantics of $\Lambda$) never duplicates a subterm and never allocates a fresh node. We prove this as \autoref{thm:55}, the no-allocation theorem, which sharpens \autoref{thm:50} by replacing its semantic hypothesis with a typing discipline.

\begin{definition}[Affine type system]\label{def:lambda}
The types of $\Lambda$ are generated from a fixed set $\mathsf{B}$ of \emph{base types} by the grammar
\[
A, B \;\;::=\;\; \beta \;\mid\; A \multimap B \;\mid\; A \otimes B \;\mid\; I,
\qquad \beta \in \mathsf{B},
\]
where $A \multimap B$ is the linear function type, $A \otimes B$ the tensor, and $I$ the unit. A \emph{linear context} is a finite partial map from variables to types; contexts are combined by the disjoint union $\Gamma, \Delta$, defined only when the domains of $\Gamma$ and $\Delta$ are disjoint, and the rules below ensure that no derivable context assigns a type to any variable twice. The \emph{terms} are generated by the grammar
\[
t, u \;\;::=\;\; x \;\mid\; a \;\mid\; t ; u \;\mid\; t \otimes u \;\mid\; (),
\]
where $x$ ranges over variables and $a$ ranges over a fixed \emph{signature} $\Sigma$ of \emph{atom constants} $a : A \multimap B$ (the atom library of \autoref{ch:mol}); $t ; u$ is \emph{composition} (the cut), $t \otimes u$ the tensor of terms, and $()$ the unit term.
The typing rules derive judgments $\Gamma \vdash t : A$; they are the rules of multiplicative intuitionistic linear logic restricted to this syntax:
\begin{enumerate}
\item[(var)] $x : A \vdash x : A$;
\item[(atom)] $\vdash a : A \multimap B$ for every atom $a : A \multimap B$ in $\Sigma$;
\item[(comp)] from $\Gamma \vdash t : A \multimap B$ and $\Delta \vdash u : A$ with $\Gamma$ and $\Delta$ disjoint, $\Gamma, \Delta \vdash t ; u : B$;
\item[(tensor)] from $\Gamma \vdash t : A$ and $\Delta \vdash u : B$ with $\Gamma$ and $\Delta$ disjoint, $\Gamma, \Delta \vdash t \otimes u : A \otimes B$;
\item[(unit)] $\vdash () : I$.
\end{enumerate}
There are no rules of weakening or contraction: a variable cannot be dropped and cannot be duplicated. A \emph{molecule term} is a closed well-typed term, i.e.\ a derivable judgment $\vdash t : A$ with empty context; these are the molecules of Mol in the fragment generated by composition and tensor.
\end{definition}

\begin{definition}[Operational semantics of $\Lambda$]\label{def:lambda-op}
The reduction relation $t \longrightarrow t'$ on well-typed terms is the smallest relation closed under the term constructors (if $t \longrightarrow t'$ then $t ; u \longrightarrow t' ; u$, $u ; t \longrightarrow u ; t'$, $t \otimes u \longrightarrow t' \otimes u$, and $u \otimes t \longrightarrow u \otimes t'$) and containing the following redex rules.
\begin{enumerate}
\item[(CE)] \emph{Composition elimination} (associativity of the cut): $(t ; u) ; v \longrightarrow t ; (u ; v)$.
\item[(TE)] \emph{Tensor elimination} (interchange): for $t : A \multimap B$, $u : C \multimap D$, $v : B \multimap E$, $w : D \multimap F$,
\[
(t \otimes u) ; (v \otimes w) \longrightarrow (t ; v) \otimes (u ; w).
\]
\item[(UE)] \emph{Unit elimination}: $t \otimes () \longrightarrow t$ and $() \otimes t \longrightarrow t$.
\end{enumerate}
Rule (CE) reassociates a pipeline so that composition is flattened; rule (TE) is the interchange law of \autoref{thm:11}, eliminating a cut whose two premises are tensor introductions by pushing the cut into its components; rule (UE) eliminates a tensor with the unit. Every rule consumes exactly one redex (the displayed term occurrence) and its right-hand side is built from subterms of that redex. We work up to the strict-monoidal convention for the unit, identifying $A \otimes I \equiv A \equiv I \otimes A$(the convention of Mol, whose tensor unit is the empty tuple) so that the unit rules preserve types.
\end{definition}

\begin{lemma}[Subject reduction]\label{lem:subject-reduction}
If $\Gamma \vdash t : A$ and $t \longrightarrow t'$, then $\Gamma \vdash t' : A$.
\end{lemma}

\begin{proof}
It suffices to check the redex rules; the congruence steps then follow by the typing rules. Rule (CE): if $(t ; u) ; v : B$, then $t : A \multimap B'$, $u : A$, and $v : B' \multimap B$ for some $A$, $B'$; the reduct $t ; (u ; v)$ derives the same type $B$ by two applications of (comp). Rule (TE): with the displayed types, the left-hand side has type $(A \otimes C) \multimap (E \otimes F)$; the reduct $(t ; v) \otimes (u ; w)$ has components of type $A \multimap E$ and $C \multimap F$ by (comp), hence the same type by (tensor). Rule (UE): $t \otimes ()$ has type $A \otimes I$, identified with $A$ by the strict-monoidal convention, and the reduct $t$ has type $A$; symmetrically for $() \otimes t$. Every redex rule therefore preserves the judgment, and induction on the derivation of the reduction (the congruence rules compose derivations of the same judgment) gives subject reduction.
\end{proof}

\begin{theorem}[The no-allocation theorem, \autoref{thm:55} [N]]\label{thm:55}
Let $\Lambda$ be the affine type system of \autoref{def:lambda} with the operational semantics of \autoref{def:lambda-op}. Then:
\begin{enumerate}
\item[(i)] \emph{Linearity invariant.} In every derivation of a judgment $\Gamma \vdash t : A$, every variable of $\Gamma$ occurs exactly once in $t$: each free variable is consumed by exactly one rule instance.
\item[(ii)] \emph{No duplication.} Every reduction rule of the operational semantics is non-duplicating: no rule copies a subterm.
\item[(iii)] \emph{No allocation.} The evaluation of every well-typed closed molecule term is a finite reduction sequence, and no step of it allocates fresh memory: every step consumes one redex and produces only subterms already present, so the set of allocated addresses is bounded by the initial term; consequently well-typed molecules run with zero heap allocation.
\item[(iv)] This sharpens \autoref{thm:50}: there the exact-once hypothesis is assumed of the atoms; here it is enforced by the type system rather than assumed. Rust's ownership (move semantics as linear consumption, borrows as read-only views that carry no resource) is the operational realization of $\Lambda$.
\end{enumerate}
\end{theorem}

\begin{proof}
(i) By induction on the derivation of $\Gamma \vdash t : A$. Rule (var): the judgment is $x : A \vdash x : A$, and the variable $x$ occurs exactly once in $x$. Rules (atom) and (unit): the context is empty, so there is nothing to check. Rule (comp): the derivation ends in $\Gamma, \Delta \vdash t ; u : B$ with the domains of $\Gamma$ and $\Delta$ disjoint; by the induction hypothesis every variable of $\Gamma$ occurs exactly once in $t$ and every variable of $\Delta$ exactly once in $u$, and since the domains are disjoint, every variable of $\Gamma, \Delta$ occurs exactly once in the composite $t ; u$, whose free variables are exactly the union of the two domains. Rule (tensor) is the same argument with $t \otimes u$ in place of $t ; u$. This is precisely where the disjointness conditions act: without them, a variable could occur in both premises and hence twice in the conclusion, i.e.\ be consumed twice. The same induction shows that every derivable context assigns each variable at most one type, so the system admits neither contraction nor weakening, and the invariant holds for every well-typed term, closed or open.
(ii) Case analysis on the reduction rules of \autoref{def:lambda-op}. Rule (CE): the redex $(t ; u) ; v$ contains the subterms $t$, $u$, $v$ once each, and the reduct $t ; (u ; v)$ contains exactly those subterms, once each: no subterm is copied. Rule (TE): the redex $(t \otimes u) ; (v \otimes w)$ contains $t, u, v, w$ once each; the reduct $(t ; v) \otimes (u ; w)$ contains exactly the same four subterms, once each. Rule (UE): the redex $t \otimes ()$ (or $() \otimes t$) contains $t$ once and the closed unit term $()$; the reduct is $t$: nothing is copied, and the only subterm erased is the closed unit term, which carries no variable. Hence no rule copies a subterm. The linearity invariant is what makes this structural fact type-theoretically necessary: by subject reduction (\autoref{lem:subject-reduction}) every reduct of a well-typed term is well-typed, and by (i) a well-typed term uses every free variable exactly once; a duplicating step would produce a well-typed term with some free variable occurring twice, contradicting (i). So the reduction rules of $\Lambda$ are exactly the non-duplicating ones, and reduction in $\Lambda$ never duplicates data.
(iii) We first show that every reduction sequence is finite. Define three measures on terms: $|t|$, the number of nodes of the syntax tree of $t$; $p (t)$, the number of pairs $(m, n)$ of composition nodes of $t$ such that $m$ lies in the left subtree of $n$; and $q (t)$, the number of pairs $(m, n)$ with $m$ a tensor node and $n$ a composition node such that $m$ lies in the left subtree of $n$. Order these lexicographically, $M (t) = (q (t), p (t), |t|)$, compared componentwise from the first. All three measures are additive over subterms, so it suffices to check the redex rules. Write $c_x$ for the number of composition nodes of $x$ and $d_x$ for the number of tensor nodes. Rule (CE): on the left-hand side $(t ; u) ; v$ the outer composition node has left subtree $(t ; u)$, containing $c_t + c_u$ composition nodes and $d_t + d_u$ tensor nodes, and the inner node has left subtree $t$; on the right-hand side $t ; (u ; v)$ the outer node has left subtree $t$ and the inner node left subtree $u$. Hence $q$ decreases by $d_t$, and if $d_t = 0$ then $p$ decreases by $c_t + 1 \geq 1$; in either case $M$ strictly decreases.
Rule (TE): on $(t \otimes u) ; (v \otimes w)$ the unique composition node has left subtree $t \otimes u$, containing $d_t + d_u + 1$ tensor nodes; on $(t ; v) \otimes (u ; w)$ the two composition nodes have left subtrees $t$ and $u$, contributing $d_t + d_u$; so $q$ decreases by exactly $1$. Rule (UE): the measures $q$ and $p$ are unchanged, but $|t \otimes ()| = |t| + 2 > |t|$ (and symmetrically for $() \otimes t$), so the third component strictly decreases. Every reduction step therefore strictly decreases the lexicographic triple $M (t) \in \mathbb{N}^3$, and $\mathbb{N}^3$ with the lexicographic order is well-founded, so no infinite reduction sequence exists: the evaluation of every well-typed closed molecule term is a finite sequence $t_0 \longrightarrow t_1 \longrightarrow \cdots \longrightarrow t_k$.
It remains to show that no step of the sequence allocates. Each redex rule replaces the redex by a term whose nodes are all nodes of the redex: rule (CE) reuses the subterms $t, u, v$; rule (TE) reuses $t, u, v, w$; rule (UE) reuses $t$ and erases the closed unit term; and the congruence rules only relocate the redex deeper into the term. Hence by induction along the sequence, every node of every reduct $t_j$ is a node (a subterm occurrence) of the initial term $t_0$. The allocation count of the step $t_j \longrightarrow t_{j+1}$, defined as the number of fresh nodes it introduces, is therefore $0$ for every $j$: every step consumes one redex and produces only subterms already present. The set of addresses occupied during the evaluation is consequently contained in the set of addresses of $t_0$ and bounded by $|t_0|$, so the peak live memory is bounded by the initial term, and well-typed molecules run with zero heap allocation.
\end{proof}

\paragraph{Ownership in Rust.}
Item (iv) is the content of the theorem for the runtime. In \autoref{thm:50}, exact-once consumption is a hypothesis to be verified of each atom; \autoref{thm:55} upgrades it to a consequence of typing, so it holds of every well-typed molecule by construction, before the program runs. Rust's ownership realizes $\Lambda$ operationally. \emph{Move} semantics are linear consumption: a moved value is transferred to exactly one new owner and the old binding is invalidated: the (comp) rule passing a datum from the producer that owns it to the consumer that consumes it, each free variable consumed by exactly one rule instance. \emph{Borrows} are read-only views: a borrow carries no ownership and hence no resource obligation, so a borrowed datum is not a variable occurrence of the term and is not counted by the linearity invariant; the borrow checker's rule that a value cannot be moved while borrowed is the dynamic shadow of the disjointness conditions of the (comp) and (tensor) rules. Where \autoref{thm:50} proves that linear atoms force zero allocation given preallocated buffers, \autoref{thm:55} proves the type-level content: well-typed molecules are linear by construction, their evaluation duplicates nothing and allocates nothing, and cut elimination as deforestation (\autoref{thm:49}) is the composition-elimination rule (CE), which computes a fused pipeline without materializing the cut formula \citep{wadler}.

\paragraph{Remark (scope of the guarantee).}
\autoref{thm:55} is a guarantee about the fragment of Mol generated by composition, tensor, and the unit: the affine core of the language of \autoref{ch:mol}. It is the type-level counterpart of the buffer-level guarantee of \autoref{thm:50}: the type system makes exact-once consumption structural, so the allocation-free execution of \autoref{thm:50} (iii) is available to every well-typed molecule without per-atom verification. This is the ownership discipline of Rust realized as an affine type system.
